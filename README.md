7. 🎁 **Gift Sets & Combos** — Curated boutique hampers & velvet festival gift boxes

## 🛠️ Tech Stack & Features

- **Frontend**: React 19, React Router (HashRouter for GitHub Pages), Tailwind CSS v4, Lucide Icons, Framer Motion
- **Deployment**: Automatic GitHub Actions workflow to GitHub Pages on every push to `main`
- **Features**: Cart drawer, Wishlist, Quick View modal, Pincode delivery estimator, Coupon discount calculator, Customer reviews & Admin portal
